🐦 Flappy Bird Web Game

A browser-based Flappy Bird game built with HTML, CSS, and JavaScript.

🎮 Live Demo

"Play Flappy Bird Online" (https://flappybird-webgame00.netlify.app/)

✨ Features

- Simple and interactive gameplay
- Keyboard and mouse controls
- Mobile-friendly tap controls
- Score-based gameplay
- Custom game graphics

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

🚀 Run Locally

1. Clone this repository:
   
   git clone https://github.com/jewel018/flappy-bird-web-game.git

2. Open the project folder.

3. Open "index.html" in your browser.

📁 Project Structure

- "index.html" — Game structure
- "style.css" — Styling and layout
- "game.js" — Game logic
- "flappybird.png" — Bird graphic
- "flappybirdbg.png" — Background graphic
- "bottompipe.png" — Bottom pipe graphic
- "toppipe.png" — Top pipe graphic
